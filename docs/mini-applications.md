# Mini Applications

These applications were reviewed from the available source code and project documentation. They are kept as separate standalone programs inside the repository.

## 1. Cashier System

A menu-driven cashier program.

**Main concepts**
- Arrays
- Strings
- Menu-based control flow
- Product and price storage
- Total calculation
- Payment and change calculation
- Input validation

The repository keeps the cleaner array-based version from the available project files and removes the earlier duplicated implementation.

## 2. GPA Calculator

A console application that accepts a number of courses, course grades, and credit hours, then calculates the GPA using weighted grade points.

**Main concepts**
- Loops
- Conditional/switch-based grade mapping
- Credit-hour weighting
- Floating-point calculations
- Console input/output

The duplicated source copies were consolidated into one repository version.

## 3. Bank / ATM System

A simple ATM simulation.

**Main concepts**
- Functions
- Pointers
- While/do-while loops
- Switch/menu control
- Balance display
- Withdrawal validation

The implementation uses a pointer to the balance and passes it to functions that display or update the balance.

## 4. Calories Calculator

A console-based calorie calculator using a small food database.

**Main concepts**
- `std::map`
- Key/value lookup
- Loops
- User input
- Quantity-based calorie calculation

The available project materials describe the application as a practical C++ console exercise using a food/calorie database.

## 5. Number Guessing Game

A simple game based on a randomly generated number from 1 to 100.

**Main concepts**
- `rand()` / `srand()`
- Random number generation
- Input-range validation
- Loops
- Conditional logic
- Feedback based on the distance from the target
