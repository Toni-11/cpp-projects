# Cashier System — Presentation Notes

**Coursework project:** C++ Programming Project — Cashier System  
**Created by:** Antton Mikhael

## Project Idea
A simple console-based cashier system built with C++ and arrays.

## Main Features
- Add up to 5 products.
- Display products and prices.
- Calculate the total price.
- Process payment and calculate change.
- Exit the system.

## Concepts Highlighted
- C++ fundamentals.
- Arrays and basic data storage.
- Procedural programming.
- Input/output.
- Menu-driven program structure.

- C++
- Visual Studio
