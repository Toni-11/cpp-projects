# C++ Programming & Data Structures Practice

A structured collection of C++ coursework and hands-on programming practice developed during the early stage of an Artificial Intelligence undergraduate program.

## What this repository contains

### Mini Applications
- Cashier System
- Bank / ATM System
- Calories Calculator
- GPA Calculator
- Number Guessing Game

### Programming Fundamentals
- Arrays and matrices
- Strings and structures
- Pointers and dynamic memory
- Functions, conditions, loops, and recursion

### Data Structures
- Singly, doubly, and circular linked lists
- Stacks and queues
- Circular queues, deques, and priority queues
- Binary trees and Binary Search Trees
- Graphs
- Hash tables

### Algorithms
- Linear and binary search
- Bubble, selection, insertion, and heap sort

## Repository organization

The collection is intentionally presented as academic practice rather than as a set of production applications. Small exercises demonstrate individual concepts, while the mini applications show how those concepts were combined into menu-driven console programs.

The repository was consolidated from multiple supplied coursework archives. Where the same exercise appeared more than once, one representative copy is retained. The stronger Cashier System implementation was preferred because it uses arrays and loops rather than separate variables for each item.

## Coursework presentations

The supplied coursework archives also contained presentation material for selected mini applications, including the Cashier System, ATM Machine Simulation, Number Guessing Game, and Calories Calculator. The repository preserves the technical context of those presentations in its documentation while keeping generated Visual Studio files out of source control.

## Academic context

These projects were developed as coursework and practical training in a Faculty of Artificial Intelligence.

## Code quality decisions

Noticeable correctness issues found during review were fixed before keeping the programs as representative examples. In particular:

- The GPA Calculator now validates course count, credit hours, and grades.
- The ATM program now rejects invalid and non-positive withdrawal amounts.
- The Calories Calculator now validates food selection and positive quantities.
- The Number Guessing Game now has a reachable correct-guess condition and robust numeric input handling.

Files that were empty, duplicated, generated by Visual Studio, or otherwise not useful as source material are not included.

## Running the programs

Use a C++17-compatible compiler, for example:

```bash
g++ path/to/program.cpp -std=c++17 -o program
./program
```

Or open the desired source file in Visual Studio and build it with a C++17-compatible configuration.

## Repository hygiene

Visual Studio caches, `.vs` folders, build output, executables, debug symbols, and other generated files are intentionally excluded from version control.
